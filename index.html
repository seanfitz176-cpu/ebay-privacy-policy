Privacy Policy — Gold Gallery Automation

Effective date: 25 October 2026.

Who this covers

Gold Gallery Automation is a private, single-operator application built and run by Sean Fitzgerald ("the operator") to manage the operator's own eBay seller account. It is not offered as a public or multi-user service, and no other person's eBay account is connected to it.

What data this application accesses

When the operator connects it to eBay through eBay's OAuth sign-in, the application accesses only the categories of data covered by the permissions the operator explicitly grants at that time, which may include: basic eBay account identity, listing and inventory data, order and fulfillment data, and seller account/business policy data. It only ever acts on the one eBay seller account the operator connects; it does not access any other eBay user's data.

How this data is used

Data is used solely to operate the operator's own eBay seller account: creating and updating listings, adjusting prices and quantities, and related account-management tasks the operator has explicitly enabled. It is not used for any other purpose.

Where this data is stored

All data is stored locally on the operator's own computer, in an encrypted local database. It is not uploaded to any third-party server, and this application has no cloud database of its own.

Sharing and sale of data

This data is never sold, rented, or shared with any third party, advertiser, or analytics service.

Retention and deletion

Data is retained only for as long as the operator continues to use the application to manage this eBay account. The operator can revoke this application's access at any time from eBay's account settings, after which the application can no longer retrieve new data; previously stored local data can be deleted by the operator at any time.

Account-deletion notifications

In compliance with eBay's Marketplace Account Deletion/Closure requirements, if any eBay account (including the operator's own) is closed, this application deletes any data it holds about that account.
